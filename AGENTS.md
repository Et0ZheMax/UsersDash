# AGENTS

- Используйте русский язык в описаниях и комментариях, если иное не требуется.
- Заголовки Markdown пишите в sentence case и делайте информативными.
- Форматируйте текстовые файлы с переносами строк до ~120 символов.
- Перед изменениями изучайте текущее поведение и сохраняйте уже принятый стиль кода и шаблонов.
- Если добавляете Python-файлы, обеспечьте наличие понятных docstring'ов и типовых подсказок там, где это
  упрощает чтение.
- Требования в `requirements*.txt` держите отсортированными по алфавиту и с минимально необходимыми
  версиями.
- По возможности запускайте `python -m unittest discover` перед коммитом и фиксируйте результат в описании
  работы.
- Для runtime-конфига entrypoint-скриптов RSSv7/RSS4SALE используйте общий загрузчик `shared/env_loader.py`,
  чтобы подхватывать корневой `/.env` без перезаписи уже заданных системных переменных.
- Для README и прочей документации добавляйте короткие инструкции по запуску и тестированию, чтобы новички
  могли быстро включиться в работу.
- В этом репозитории вместе с UsersDash лежат Windows-сборки `RSSv7` и `RSS4SALE`. При правках не ломайте
  пути для Windows и помечайте, если нужен запуск от администратора или конкретные версии Python.
- Описывайте изменения в README/AGENTS при добавлении новых утилит, конфигов или шаблонов, особенно в
  каталогах `UsersDash/bot_farm_configs`, `RSSv7` и `RSS4SALE`.

## Контекст утилит переноса LDPlayer

- `RSSv7/LD_Symbolic_move/ldplayer_mover.py` и `ldplayer_mover_gui.pyw` обслуживают постоянный перенос ВМ из
  штатного `C:\LDPlayer\LDPlayer9\vms` на резервный диск (по умолчанию `V:\vms`). На C остаётся junction,
  поэтому LDPlayer продолжает видеть прежний путь.
- `RSSv7/LD_Symbolic_move/ld_emul_symbolic_fix.py` — более старая утилита с другим направлением и жизненным
  циклом: она временно переносит ВМ из внешнего хранилища для запуска и затем возвращает обратно. Не считайте
  эти сценарии взаимозаменяемыми.
- При изменении нового переносчика сохраняйте транзакционную последовательность: копирование во временный
  каталог, проверка копии, атомарное переименование, создание ссылки и только затем удаление оригинала.
- Не обходите проверки reparse point, коллизии целевой папки, свободного места и процессов LDPlayer. Операция
  не должна удалять каталог назначения, если он не был создан текущей транзакцией.
- Runtime-зависимостей вне стандартной библиотеки нет; GUI использует Tkinter. Базовая проверка:
  `python RSSv7/LD_Symbolic_move/test_ldplayer_mover.py` на Windows.
