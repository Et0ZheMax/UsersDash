# Повторная авторизация VikingLogin

VikingLogin запускает выбранный существующий эмулятор LDPlayer и повторно входит в Viking Rise через IGG.
Утилита не клонирует, не удаляет и не переименовывает эмуляторы, а также не изменяет профиль GnBots.

Связь между эмулятором и фермой определяется строго по `InstanceId` активного профиля GnBots. Названия могут
отличаться: это не влияет на выбор учётных данных. Если один LDPlayer используется несколькими фермами, он
отображается отдельной строкой для каждой из них. Чистый образ LDPlayer ID 0 намеренно не показывается.

## Запуск

1. Запустите ярлык **VikingLogin** на рабочем столе сервера.
2. Выберите существующий эмулятор, у которого в колонке **Готовность** указано **Да**.
3. Нажмите **Авторизовать выбранный эмулятор** и подтвердите действие.
4. Дождитесь зелёного сообщения и системного сигнала об успешном входе.

Операцию можно отменить в безопасной точке. Пароли не отображаются и не записываются в журнал. Журнал
находится в `logs\viking_login.log`.

## Консольная диагностика

Показать привязки без секретов:

```bat
py -3 viking_login.py --list
```

Проверить конкретную ферму без запуска LDPlayer:

```bat
py -3 viking_login.py --farm Akhm2 --dry-run
```

## Тесты

```bat
py -3 -m unittest -v test_viking_login.py
```
