# Перенос ВМ LDPlayer между дисками

Каталог содержит две разные утилиты:

- `ldplayer_mover.py` и `ldplayer_mover_gui.pyw` — безопасный постоянный перенос ВМ из штатной папки LDPlayer
  на резервный диск с junction на исходном месте;
- `ld_emul_symbolic_fix.py` — старый сценарий временного переноса ВМ из внешнего хранилища для запуска и
  последующего возврата.

Не смешивайте направления переноса этих сценариев.

## Быстрый запуск GUI

1. Полностью закройте LDPlayer и менеджер мультиокон.
2. Запустите `run_ldplayer_mover.bat` двойным щелчком или выполните
   `python ldplayer_mover_gui.pyw` из этого каталога.
3. Проверьте пути. По умолчанию используются:
   - источник: `C:\LDPlayer\LDPlayer9\vms`;
   - назначение: `V:\vms`.
4. Нажмите «Сканировать». Рекомендуемые ВМ будут отмечены автоматически; выбор меняется двойным щелчком.
5. Нажмите «Перенести выбранные» и подтвердите операцию.

Для запуска исходников нужен Python 3.10 или новее. Сторонние runtime-библиотеки не используются: GUI
построен на Tkinter из стандартной поставки Python для Windows.

## Логика рекомендации

По умолчанию к переносу рекомендуются доступные ВМ с чётными номерами. Получается чередование: `leidian7`
остаётся на C, `leidian8` переносится, `leidian9` остаётся на C. Это простая эвристика распределения дисковой
нагрузки; оператор может выбрать любые доступные строки вручную.

Уже перенесённые junction/symlink, нечитаемые каталоги и коллизии с существующей папкой назначения не входят
в доступный выбор.

## Гарантии безопасного переноса

Для каждой ВМ программа:

1. проверяет, что LDPlayer и его headless-процессы остановлены;
2. копирует данные во временный каталог резервного диска;
3. повторно сверяет список и размеры файлов в источнике и копии;
4. переименовывает проверенную копию в итоговую папку;
5. временно переименовывает оригинал и создаёт junction по старому пути;
6. удаляет оригинал только после успешного создания ссылки.

При обычной ошибке выполняется откат. Служебный JSON-журнал позволяет следующему запуску восстановить или
завершить операцию после внезапной перезагрузки. Скрипт никогда не должен удалять существующий каталог
назначения, который не был создан текущей транзакцией.

## Консольный режим

```powershell
python .\ldplayer_mover.py
python .\ldplayer_mover.py --scan-only
python .\ldplayer_mover.py --source "C:\LDPlayer\LDPlayer9\vms" --destination "D:\vms"
python .\ldplayer_mover.py --link-type symlink
```

По умолчанию создаётся junction, который обычно не требует прав администратора. Настоящая symbolic link
может потребовать Developer Mode Windows или запуск терминала от администратора.

## Тестирование и сборка EXE

Проверка исходников на Windows:

```powershell
python .\test_ldplayer_mover.py
python -m py_compile .\ldplayer_mover.py .\ldplayer_mover_gui.pyw
```

Опциональную автономную сборку без установленного Python можно создать через PyInstaller (это только
build-зависимость, а не runtime-зависимость проекта):

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed `
  --name LDPlayer_VM_Mover .\ldplayer_mover_gui.pyw
```

Полученный `dist\LDPlayer_VM_Mover.exe` можно положить рядом с BAT-файлом: launcher выберет EXE первым.
