# Алерты Android с именами аккаунтов

`emulator_health.py` проверяет окна LDPlayer, процессы виртуальных машин и
`sys.boot_completed` через ADB с ограничением времени. Имена берутся из
`C:\Program Files\GnBots\config.json` → `SelectedProfile` → `profiles/<профиль>.json`,
по полям `InstanceId` и `Name`. Привязка перечитывается при каждом проходе.

Пример: `• Oo2 (LDPlayer 52): Android не загрузился / ADB offline`.
Если профиль недоступен или один индекс связан с разными именами, остаётся номер.
Пароли, содержимое `MenuData` и параметры действий не выводятся.

Сбой подтверждается в течение трёх минут. Повтор по тому же индексу отправляется
не чаще раза в 30 минут, включая исчезновение и перезапуск окна. Новый неисправный
экземпляр и массовый отказ могут вызвать отдельное уведомление. Время отправки
сохраняется только после подтверждения Telegram.

Это отдельный монитор: он не перезапускает Windows, GnBots или эмуляторы.
Существующие задачи восстановления сохраняются. Telegram использует настройки
`Gn_Ld_Check.py` и корневой `.env`, загружаемый через `shared/env_loader.py`.
Секреты и рабочие данные в коммит добавлять не нужно.

## Проверка и установка

Нужны Windows, Python 3.10+ и зависимости существующего `Gn_Ld_Check.py`
(включая `psutil` и `python-telegram-bot`). Путь к Python должен быть доступен SYSTEM.
Из каталога `RSSv7/Gn_LD_Check`:

```powershell
python -m unittest discover -p 'test*.py'
python emulator_health.py --dry-run --server-label 208
```

Для установки запустите PowerShell от администратора и укажите фактический Python:

```powershell
.\Install-EmulatorHealth.ps1 -PythonPath 'C:\Python313\python.exe' -ServerLabel 208
```

Задача `BotOps-EmulatorHealth` работает от SYSTEM при загрузке и каждую минуту.
Одновременные проходы запрещены, время выполнения ограничено двумя минутами.
История проверок: `data/emulator_health.runtime.log`, состояние и дедупликация:
`data/emulator_health.json`. Эти файлы локальны для каждого сервера.
Без `--server-label` используется имя Windows-хоста; также поддерживается
`GNLDCHECK_SERVER_LABEL` из окружения или корневого `.env`.

## Откат

Перед заменой файлов временно отключите монитор и дождитесь окончания прохода.
После замены верните прежнее Enabled-состояние задачи. Установщик сохраняет XML
существующей задачи в `data/EmulatorHealth.before-*.xml` перед её обновлением.
При первой установке удаление только `BotOps-EmulatorHealth` отключает новый монитор.
Не откатывайте файл состояния после новых отправок: это приведёт к повторным алертам.
